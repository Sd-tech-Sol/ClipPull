# ClipPull v0.6.0

ClipPull v0.6.0 is a product-polish and reliability release for the portable
Windows downloader.

## Highlights

- **More reliable Auto video downloads.** ClipPull still prefers a fast,
  ready-to-use combined stream, then transparently falls back to separate
  video and audio streams with a verified FFmpeg installation when the
  combined format is unavailable.
- **English and French interface.** All new settings, update, progress, queue,
  and About text is available in both languages and updates at runtime.
- **Persistent preferences.** Output folder, format, quality, history, browser
  session choice, playlist limit, update preference, theme, language, and
  window size/state are restored between launches.
- **ClipPull update notifications.** A safe, non-blocking GitHub Releases check
  can notify you about a newer public version and open its official release
  page. ClipPull does not download or run application updates automatically.
- **Clearer downloads.** Active queue rows show download speed and ETA when
  yt-dlp provides them, and waiting or finished items can be removed from the
  visible queue. The active item must be cancelled before removal.
- **About / À propos.** Settings now includes the current version, project and
  license links, third-party acknowledgements, and the AI-assistance disclosure.
- **Subtitles.** A new Subtitles section lets you download subtitles with the
  media or on their own (no video/audio download), choose Automatic/English/
  French/all available languages, and optionally fall back to auto-generated
  captions when no official subtitle exists. Official subtitles are always
  preferred over automatic ones for the same language, "All available" never
  pulls in machine-translated caption sets, and ClipPull saves an `.srt`
  sidecar file directly when possible, converting with the existing verified
  FFmpeg only when needed and only with your confirmation. A subtitles-only
  request never touches the media download history, so it works even for
  media you already downloaded.
- **More reliable update checks.** A failed automatic update check (offline,
  rate-limited) no longer silences checks for the rest of the 18-hour window,
  and the check is cancelled cleanly when ClipPull closes.

ClipPull continues to verify yt-dlp and approved FFmpeg downloads by SHA-256,
ignores external yt-dlp configuration and plugins, requires no account, sends
no ClipPull telemetry, and keeps history and settings locally.
